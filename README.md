# NEMA 23 Torque vs. Speed Plot

A small Python script that reads motor speed and torque data from a CSV file and plots the torque-speed curve of a NEMA 23 stepper motor using Matplotlib.

## What it does

1. Reads `nema23_torque_vs_rpm.csv` with Python's built-in `csv` module.
2. Skips the header row and converts both columns to `float`.
3. Plots torque (N·m) against speed (RPM) with square markers, axis labels, title, legend and grid.
4. Keeps the plot window open until Enter is pressed.

## Files

| File | Description |
|------|-------------|
| `plot_torque.py` | The plotting script |
| `nema23_torque_vs_rpm.csv` | Data: column 1 = speed (RPM), column 2 = torque (N·m) |
| `README.md` | This file |

## Data source

The CSV was generated by Claude in an earlier chat about motor speed and torque. The values are therefore **approximate and illustrative**, not measured data and not copied from a manufacturer datasheet. For any real design or report, replace them with values from the datasheet of your exact motor/driver combination (the curve depends on supply voltage, driver current and microstepping) or with your own measurements.

## Requirements

- Python 3
- Matplotlib: `pip install matplotlib`

## Usage

Put the script and the CSV in the same folder, then run:

```bash
python main.py
```

## Script

```python
import matplotlib.pyplot as plot
import csv


rpm, torque = [],[] 

with open ("nema23_torque_vs_rpm.csv","r") as file:
    reader = csv.reader(file)
    next(reader)
    for i in reader:
        rpm.append(i[0])
        torque.append(i[1])

plot.title("Speed and Torque relationo of Motor")
plot.plot(rpm,torque, label="Legend", color="red")
plot.xlabel("Speed (rpm)")
plot.ylabel("Torque (nm)")
plot.legend()
plot.grid()
plot.ioff()
plot.show()
```

## Notes and fixes made along the way

- `pyplot` has no `__version__`; use `matplotlib.__version__`.
- `csv.reader` yields rows, not columns, so the values are collected in a loop.
- CSV values are strings; they are converted with `float()` so the axes are numeric.
- Legend labels are set with `label=` in `plot()`, then `plt.legend()` is called without arguments.
- `marker="s"` gives square markers (`"o"` circle, `"^"` triangle, `"D"` diamond).
- `plt.show(block=False)` followed by `input()` keeps the window open until Enter is pressed. If the window freezes, add `plt.pause(0.1)` after `show`.
- `plt.subplot(1, 2, 2)` is only needed for side-by-side plots, for example torque vs. RPM next to power vs. RPM.
